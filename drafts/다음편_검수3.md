# 15~19편 텍스트 제안 (2026-10-16, 검수 전)
규칙: 된소리 ッ, 돼=ドェ, 놔=ノァ, 금지는 ~지 마세요. 사전 대조 전

## 15편 道に迷った時に使う韓国語 (존댓말)
1. 여기가 어디예요?（ヨギガ オディエヨ）＝ ここはどこですか？
2. 길을 잃었어요（キルル イロッソヨ）＝ 道に迷いました
3. 이 근처에 지하철역 있어요?（イ クンチョエ チハチョルリョク イッソヨ）＝ この近くに地下鉄の駅はありますか？
4. 걸어서 갈 수 있어요?（コロソ カル ッス イッソヨ）＝ 歩いて行けますか？

## 16편 好きな人に告白する時に使う韓国語 (반말)
1. 할 말 있어（ハル マル イッソ）＝ 話があるの
2. 너 좋아해（ノ チョアヘ）＝ あなたが好き
3. 나랑 사귈래?（ナラン サグィルレ）＝ 付き合ってくれる？
4. 대답은 천천히 해도 돼（テダブン チョンチョニ ヘド ドェ）＝ 返事はゆっくりでいいよ

## 17편 空港で荷物が出てこない時に使う韓国語 (존댓말)
1. 제 짐이 안 나왔어요（チェ チミ アン ナワッソヨ）＝ 私の荷物が出てきません
2. 어디로 가면 돼요?（オディロ カミョン ドェヨ）＝ どこに行けばいいですか？
3. 연락처 여기 있어요（ヨルラクチョ ヨギ イッソヨ）＝ 連絡先はこちらです
4. 호텔로 보내 주세요（ホテルロ ポネ ジュセヨ）＝ ホテルに送ってください

## 18편 酔った友達に使う韓国語 (반말, 웃음형)
1. 너 취했어（ノ チュィヘッソ）＝ 酔ってるよ
2. 그만 마셔（クマン マショ）＝ もう飲むのやめて
3. 집에 가자（チベ カジャ）＝ 家に帰ろう
4. 내일 기억 안 날걸（ネイル キオク アン ナルッコル）＝ 明日覚えてないよ

## 19편 推しの誕生日に使う韓国語 (존댓말)
1. 생일 축하해요（センイル チュカヘヨ）＝ お誕生日おめでとう
2. 태어나 줘서 고마워요（テオナ ジュォソ コマウォヨ）＝ 生まれてきてくれてありがとう
3. 앞으로도 꽃길만 걸어요（アプロド ッコッキルマン コロヨ）＝ これからも花道だけを歩いてね
4. 평생 함께해요（ピョンセン ハムッケヘヨ）＝ 一生一緒にいようね

## 확인할 것
- 15-4 갈 수=[갈쑤] → カル ッス (된소리 표기 규칙대로)
- 19-1 생일 축하해요는 쉬운 편(입문 수준 경고). 推し 편이라 넣었는데 빼면 다른 문장 제안 가능
