# 9~14편 텍스트 제안 (2026-10-16, 검수 전)

규칙: 된소리 ッ, 돼=ドェ, 사전 대조 전. 1~8편 표현과 겹치지 않게. 발행 제안: 12~17일차(10/24~10/29)

## 9편 タクシーで遠回りされた時に使う韓国語 (존댓말)
1. 이 길 맞아요?（イ ギル マジャヨ）＝ この道で合ってますか？
2. 미터기 켜 주세요（ミトギ キョ ジュセヨ）＝ メーターをつけてください
3. 여기서 세워 주세요（ヨギソ セウォ ジュセヨ）＝ ここで止めてください
4. 카드 돼요?（カドゥ ドェヨ）＝ カード使えますか？

## 10편 友達が遅刻した時に使う韓国語 (반말)
1. 어디야?（オディヤ）＝ どこ？
2. 또 늦었어?（ット ヌジョッソ）＝ また遅れたの？
3. 어이없어（オイオプソ）＝ あきれた
4. 밥 사（パプ サ）＝ ご飯おごってね

## 11편 幽霊を見た時に使う韓国語 (반말, 웃음형)
1. 엄마야!（オンマヤ）＝ きゃっ！（驚いた時の声）
2. 귀신이다（クィシニダ）＝ 幽霊だ！
3. 저리 가（チョリ ガ）＝ あっち行って
4. 나 혼자 두지 마（ナ ホンジャ トゥジ マ）＝ 一人にしないで

## 12편 美容室で使う韓国語 (존댓말)
1. 다듬어 주세요（タドゥモ ジュセヨ）＝ 整えてください
2. 너무 짧게는 말고요（ノム ッチャルッケヌン マルゴヨ）＝ 短くしすぎないでください
3. 앞머리 잘라 주세요（アムモリ チャルラ ジュセヨ）＝ 前髪を切ってください
4. 이 사진처럼 해 주세요（イ サジンチョロム ヘ ジュセヨ）＝ この写真みたいにしてください

## 13편 客引きにつかまった時に使う韓国語 (존댓말)
1. 괜찮아요（クェンチャナヨ）＝ 大丈夫です（結構です）
2. 그냥 구경만 할게요（クニャン クギョンマン ハルッケヨ）＝ 見てるだけです
3. 시간이 없어요（シガニ オプソヨ）＝ 時間がないんです
4. 이미 샀어요（イミ サッソヨ）＝ もう買いました

## 14편 寝坊した時に使う韓国語 (반말) ※배달 편 폐기(전화 안 함)
1. 망했다（マンヘッタ）＝ 終わった…
2. 알람이 안 울렸어（アルラミ アン ウルリョッソ）＝ アラームが鳴らなかった
3. 지금 가고 있어（チグム カゴ イッソ）＝ 今向かってる（本当はまだ家…）
4. 5분만 더（オブンマン ト）＝ あと5分だけ
