# tools/render_cloud.py
클라우드 세션에서 card.py 없이 카드를 그리려고 만든 임시 렌더러. 맥의 card.py가 정본이다.
폰트: Black Han Sans(한글), M PLUS Rounded 1c(일본어), Noto Sans KR. `npm i @expo-google-fonts/black-han-sans @expo-google-fonts/noto-sans-kr @expo-google-fonts/m-plus-rounded-1c`
경로(S, CARDS)는 스크립트 안에 클라우드 경로로 박혀 있으니 맥에서 쓰려면 고칠 것.
